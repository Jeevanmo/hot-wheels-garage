HOT WHEELS GARAGE — VISUAL STUDIO CODE PROJECT

HOW TO RUN
1. Extract this folder.
2. Open the Hot-Wheels-Garage folder in Visual Studio Code.
3. Install the "Live Server" extension (by Ritwick Dey).
4. Right-click index.html and choose "Open with Live Server".

FILES
- index.html: page structure
- style.css: styling and responsive layout
- script.js: products, search, filters, cart and WhatsApp order

BEFORE USING FOR REAL ORDERS
- Open script.js and replace WHATSAPP_NUMBER = "91XXXXXXXXXX" with your WhatsApp number including country code, without + or spaces.
- Replace sample products, prices and images with your actual stock. The sample prices and cars are placeholders.
- This is a front-end demo store. It does not process payments, verify stock, or save orders to a server.
- Product/hero photos load from Unsplash, so internet is required for those images and Google Fonts.
